# わが家の献立

献立を選ぶと、買う材料が売り場ごとのチェックリストで出るWebアプリです。
1週間分を決めておけば、日曜日にまとめて買い物できます。

- **献立**：日をタップして、メイン／サブ／ごはん／汁物／その他を選ぶ。「第1週〜第5週」で定番をまとめて当てはめる
- **買い物**：今日・明日・今週・来週の材料をチェックリストで表示。同じ材料は「3回分」のように数をまとめて表示し、残りはLINE用にコピーできる
- **料理リスト**：料理と材料、常備品を追加・修正する

## しくみ

```
スマホ（GitHub Pages のページ） ──操作を送る──▶ Google Apps Script ──▶ スプレッドシート
        ▲                                                            │
        └──────────────── 最新の状態を返す ◀─────────────────────────┘
```

- アプリ本体（このリポジトリ）には個人のデータを入れていません。データはご自身のGoogleスプレッドシートにだけ保存されます。
- 変更は「この日の献立をこれに」「この材料にチェック」のような**操作単位**で送ります。そのため、2人が同時に別の日の献立や別の材料を触っても、片方の変更が消えることはありません。同じ項目を同時に変えた場合は、後から届いたほうが残ります。
- 共有の設定をしなければ、その端末の中だけに保存されます（それだけでも使えます）。
- 電波がないときも、最後に読み込んだ内容が表示されます。その間の変更は端末にためておき、次につながったときに送ります。

## 準備

### 1. 保存先（Google スプレッドシート＋GAS）

1. Googleドライブで新しいスプレッドシートを作ります（名前の例：献立アプリデータ）。
2. メニューの「拡張機能」→「Apps Script」を開き、`gas/Code.gs` の中身を貼り付けて保存します。
3. 関数 `setup` を選んで「実行」します。初回は権限の確認が出るので許可してください。`data` と `log` のシートができます。
4. 「プロジェクトの設定」→「スクリプト プロパティ」で、プロパティ `KEY` を追加します。値はご自身で決めた合言葉です（どこにも書き残さないでください）。
5. 「デプロイ」→「新しいデプロイ」→ 種類は「ウェブアプリ」を選びます。
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
6. 表示された `https://script.google.com/macros/s/……/exec` のURLを控えます。

「全員」にしても、データを読み書きできるのはURLと合言葉の両方を知っている人だけです。

### 2. アプリ（GitHub Pages）

1. このリポジトリの Settings → Pages を開き、Branch を `main`、フォルダを `/ (root)` にして保存します。
2. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けるようになります。

### 3. 2人のスマホで設定

1. 上のURLを開き、右上の「設定」を押します。
2. GASのURL・合言葉・端末名（例：パパのスマホ）を入れて保存します。
3. 共有先がまだ空のときだけ「初期データを入れる」が出ます。どちらか1台で1回押してください（料理34品と定番5週が入ります）。
4. ブラウザの「ホーム画面に追加」をすると、アプリのように開けます。

## 自動で動くところと、止め方

| 動き | 内容 | 止め方 |
|---|---|---|
| 自動で最新にする | アプリを**開いている間だけ**、30秒ごとに読み込む | 設定のチェックを外す |
| 変更の送信 | 操作した直後に、設定したGASのURLへだけ送る | 設定のURLを消す |
| GAS | アプリから呼ばれたときだけ動く。トリガー（定期実行）やメール送信はなし | 「デプロイを管理」でアーカイブ |
| 記録 | 書き込みのたびに、スプレッドシートの `log` シートへ「日時・端末・操作」を記録 | — |

## 注意

- 合言葉は各スマホのブラウザに保存されます。共用の端末では設定しないでください。
- GitHub Pages を無料で使う場合、リポジトリは公開になります（コードは誰でも見られます）。合言葉やURLはコードに入っていません。
- 料理リストの編集（料理の追加・削除）は、料理リスト全体を1つとして保存します。2人が同時に料理リストを編集した場合だけ、後から保存したほうが残ります。

## ファイル

- `index.html` … アプリ本体
- `seed.js` … 初期データ（料理34品・定番5週）。「初期データを入れる」を押したときだけ使います
- `manifest.json`, `icon-*.png` … ホーム画面に追加したときの名前とアイコン
- `gas/Code.gs` … 保存用の Google Apps Script
