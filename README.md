# わが家の献立

献立を選ぶと、買う材料が売り場ごとのチェックリストで出るWebアプリです。
1週間分を決めておけば、日曜日にまとめて買い物できます。

- **献立**：日をタップして、メイン／サブ／ごはん／汁物／その他を選ぶ。「第1週〜第5週」で定番をまとめて当てはめる
- **買い物**：今日・明日・今週・来週の材料をチェックリストで表示。同じ材料は「3回分」のように数をまとめ、残りはLINE用にコピーできる
- **料理リスト**：料理と材料、常備品を追加・修正する

## しくみ

```
スマホ（GitHub Pages のページ） ──操作＋端末の鍵──▶ Google Apps Script ──▶ スプレッドシート
```

- このリポジトリには個人のデータを入れていません。データはご自身のGoogleスプレッドシートにだけ保存されます。
- 変更は「この日の献立をこれに」「この材料にチェック」のような**操作単位**で送ります。2人が同時に別の日の献立や別の材料を触っても、片方の変更が消えることはありません。
- 電波がないときも、最後に読み込んだ内容が表示されます。その間の変更は端末にためておき、次につながったときに送ります。

### 合言葉なしで守るしくみ（招待QR）

| | 内容 |
|---|---|
| 新しい端末の登録 | 登録済みの端末で「招待QR」を出し、新しい端末のカメラで読む。**10分間・1回だけ**有効 |
| 端末ごとの鍵 | 登録した端末にだけ、推測できない長い鍵を発行。以後の通信はこの鍵で確認する |
| スプレッドシートに残るもの | 鍵そのものではなく、元に戻せない形（ハッシュ）だけ |
| 1台だけ止める | `devices` シートで、その端末の「状態」を `停止` にする（または行を削除） |
| 記録 | 書き込み・招待・端末の登録を、`log` シートに「日時・端末・内容」で記録 |

GASのURLが他人に知られても、鍵がなければ読むことも書くこともできません。

## 準備（最初に1回）

### 1. 保存先（Google スプレッドシート＋GAS）

1. Googleドライブで新しいスプレッドシートを作ります（名前の例：献立アプリデータ）。
2. 「拡張機能」→「Apps Script」を開き、最初からあるコードを消して `gas/Code.gs` の中身を貼り付け、保存します。
3. 関数 `setup` を選んで「実行」します。権限の確認が出たら「詳細」→「（安全ではないページ）に移動」→「許可」と進みます。`data`・`log`・`devices` のシートができれば成功です。
4. 「デプロイ」→「新しいデプロイ」→ 種類は「ウェブアプリ」を選びます。
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
5. 表示された `https://script.google.com/macros/s/……/exec` のURLをコピーします。

### 2. アプリ（GitHub Pages）

1. このリポジトリの `config.js` を開き、鉛筆マークで編集します。`window.KONDATE_GAS = "";` の `""` の中に、手順1-5のURLを貼り付けて「Commit changes」を押します。
2. 「Settings」→「Pages」で、Branch を `main`、フォルダを `/ (root)` にして保存します。
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けるようになります。

### 3. 1台目（パパのスマホ）を登録

1. PCでスプレッドシートを開いたまま、Apps Script で関数 `createInvite` を選んで「実行」します。
2. 初回だけ「アプリのURL」を聞かれるので、手順2-3のURLを入れます。続けて端末の名前（例：パパのスマホ）を入れます。
3. スプレッドシートにQRコードが出ます。スマホのカメラで読むと、アプリが開いて接続まで済みます。
4. 共有先がまだ空なので「初期データを入れる」が出ます。1回押すと、料理34品と定番5週が入ります。

### 4. 2台目（ママのiPhone）を登録

1. パパのスマホのアプリで、右上「設定」→ 名前を確認して「招待QRを出す」を押します。
2. iPhoneのカメラでそのQRを読むと、Safariでアプリが開き、ホーム画面への追加の案内が出ます。
3. 案内のとおり、「共有」→「ホーム画面に追加」→「追加」と進みます。
4. ホーム画面にできた「献立」のアイコンから開くと、自動でつながります。
   - つながらなかったときは、QRの下に出ている8文字（例：ABCD-EFGH）を、出てきた入力欄に入れてください。

## 自動で動くところと、止め方

| 動き | 内容 | 止め方 |
|---|---|---|
| 自動で最新にする | アプリを**開いている間だけ**、30秒ごとに読み込む | 設定のチェックを外す |
| 変更の送信 | 操作した直後に、`config.js` のGASへだけ送る | 設定の「この端末の登録を外す」 |
| GAS | アプリから呼ばれたときだけ動く。トリガー（定期実行）・メール送信はなし | 1台：`devices` で `停止`／全部：「デプロイを管理」でアーカイブ |

## 注意

- 鍵は各スマホのブラウザに保存されます。Safariの「履歴とWebサイトデータを消去」をしたり、ホーム画面のアイコンを削除したりすると鍵も消えるので、そのときは招待をやり直してください。
- スマホを機種変更・紛失したときは、`devices` シートでその端末を `停止` にしてください。
- 無料の GitHub Pages ではリポジトリが公開になり、`config.js` のGASのURLも見えます。読み書きには端末の鍵が必要なので、URLだけでは何もできません。
- 料理リストの編集（料理の追加・削除）は、料理リスト全体を1つとして保存します。2人が同時に料理リストを編集した場合だけ、後から保存したほうが残ります。
- 画面右上にアプリのバージョン（例：v1.1.0）が出ます。`index.html` を更新したら、中の `const VERSION="…"` も上げてください。GitHub Pages は反映まで数分かかることがあるので、バージョン表示で新しいほうが開いているか確かめられます。
- `Code.gs` を書き換えたときは、「デプロイを管理」→ 鉛筆 →「新バージョン」で更新してください（URLは変わりません）。

## ファイル

- `index.html` … アプリ本体
- `config.js` … GASのURL（ここだけ書き換える）
- `seed.js` … 初期データ（料理34品・定番5週）。「初期データを入れる」を押したときだけ使う
- `manifest.json`, `icon-*.png` … ホーム画面に追加したときの名前とアイコン
- `gas/Code.gs` … 保存用の Google Apps Script
